# psicologIA-backend

Para rodar o servidor passo a passo abaixo

# NodeJS versão 20

1° Passo: Abra o terminal dentro do Visual Studio Code

2° Passo: Utilize o código npm install para instalar as dependências dentro sistema

3° Passo: Agora pode dar abrir o servidor com o código npm start ele irá dar algo parecido como http://localhost:3000
